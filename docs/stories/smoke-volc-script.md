# 标题
Smoke Volc Script | 便利店监控异帧事件
# 内容定位
竖屏悬疑快闪短内容，单条成片时长3-5秒，主打强情绪冲击的碎片化叙事，适配短视频平台流量逻辑，单集留足悬念引导用户追更系列内容，所有内容锚定“深夜便利店超自然异像”核心赛道。
# 角色关系
1. 显性角色：夜班店员，20岁左右的兼职打工人，作为观众代入的第一视角观察者，初始状态对异像完全不知情
2. 隐性角色：异帧人影，身份不明的超自然存在，仅能在监控画面的单帧中短暂出现，与店员暂无显性互动，是冲突的核心来源
# 世界与场景锚点
统一锚定现实向日常世界观，无超前科幻/奇幻设定前置，所有冲突从日常场景中自然生发：
- 固定时间：凌晨2:17，普通工作日深夜
- 固定场景：社区临街24小时便利店，收银台内侧摆放15寸冷光监控屏，店内是暖黄顶灯照明，玻璃门外是无行人的昏暗街道，货架整齐摆放着零食、饮品等常规商品
# 剧情钩子
店员摸鱼回看前10分钟的监控录像排查漏扫商品时，偶然瞥见回放中闪过一帧从未见过的模糊人影，抬头确认店内空无一人后，再反复拖动进度条逐帧查找，那帧人影彻底消失不见。
# 镜头节奏建议
共2个镜头节拍，总时长约4秒：
1. 节拍1（0-2s）：特写监控屏回放画面，画面中只有空荡的便利店过道，能看到店员按回放倒退键的指尖搭在屏幕边缘，环境音只有便利店冷柜的轻微嗡鸣
2. 节拍2（2-4s）：毫无预兆闪入1帧穿深色雨衣、低头站立的模糊人影监控画面，紧接着切店员瞳孔骤缩的眼部特写，最后0.3s跳黑幕，配打字机效文字「我刚才看错了？」
# 首集切入方式
无冗余铺垫直接开场，开篇第一帧就是冷白监控屏的回放画面，仅用画面边缘漏出的暖黄便利店顶灯、按按键的店员指尖交代环境和视角，开篇3秒内直接放出异帧冲击点，最大化短内容的情绪冲击力。
