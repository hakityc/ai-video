Project assets are organized by role, not by file type.

## Structure

- `assets/characters/<slug>/reference/`
  - approved still images used as identity anchors
- `assets/characters/<slug>/generation.json`
  - raw generation metadata and prompts for the current reference pack

Example:

- `assets/characters/tomb-raider-female/reference/front.jpeg`
- `assets/characters/tomb-raider-female/reference/three-quarter.jpeg`
