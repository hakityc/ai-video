# Asset Packs

This directory holds reusable visual packs that should exist before short-form video generation starts.

## Pack types

- `examples/scenes/`
  - fixed scene packs
- `examples/props/`
  - reusable prop packs and prop-state variants
- `examples/shot-templates/`
  - framing and blocking templates

## Rule

Do not generate chapter keyframes directly from raw story prompts if the required scene pack and shot template do not exist yet.
